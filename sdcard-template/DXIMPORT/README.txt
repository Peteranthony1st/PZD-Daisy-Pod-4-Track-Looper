Drop DX7 .syx files here to import them into Dexed
(Screen::Dexed -> Preset page -> Files -> Import).

Accepted: a real DX7 Single Voice Dump (one patch) or a real 32-Voice
Bulk Dump (a full bank) -- standard SysEx files, exactly as exported by
any DX7 editor/librarian. Each import gets its own named folder (named
after the file itself) under Preset -> Files -> Imports.

This README.txt is harmless to leave here -- the firmware only ever
looks for real .syx/.SYX files in this folder.
