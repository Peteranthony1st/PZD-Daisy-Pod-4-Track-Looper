Your own Dexed presets live here (PRES3130.DAT, PRES3131.DAT, ...) --
the 3129 factory presets are built into the firmware itself, not stored
as files, so only your own manual saves and SysEx imports show up here.

Created automatically the first time you save or import a Dexed
preset -- this folder is only pre-made here so a fresh card already
matches a populated one. See IMPORTS/ (inside this folder) for how
imported SysEx banks are grouped.
