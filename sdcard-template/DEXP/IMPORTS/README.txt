One small file per imported DX7 SysEx bank (IMP001.DAT, IMP002.DAT,
...) -- each just records that import's own folder name and which
range of preset numbers (in the DEXP/ folder one level up) it filled,
so the Preset -> Files -> Imports screen can show it as its own named
folder instead of one flat list.

Created automatically the first time you import a SysEx bank -- this
folder is only pre-made here so a fresh card already matches a
populated one.
