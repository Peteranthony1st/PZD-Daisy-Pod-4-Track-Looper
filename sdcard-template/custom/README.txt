44.1kHz-resampled WAV exports for MicroDexed Touch land here
(Global:Export, "CD" / Button 2).

The name "custom" is required, not cosmetic -- MicroDexed Touch scans
its SD card for a folder with exactly this name, so a card exported to
here can go straight into MicroDexed Touch's second card slot and be
picked up as a sample with no copying needed.

Created automatically the first time you export in this mode -- this
folder is only pre-made here so a fresh card already matches a
populated one.
